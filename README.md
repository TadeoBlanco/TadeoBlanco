# Sobre Mí

Mi nombre es Tadeo Blanco y soy estudiante de 4.º año de Ingeniería en Sistemas en la Universidad ORT Uruguay, con título intermedio de Ayudante de Ingeniero en Sistemas. Durante la carrera desarrollé proyectos full stack con TypeScript, Node.js, Angular y .NET, trabajando con bases de datos como PostgreSQL, MySQL y MongoDB, Docker, testing automatizado y pipelines de CI/CD. También tengo experiencia con Java, C#, C++ y Haskell, y fui Ayudante de Cátedra de Programación en ORT.

Estoy abierto a oportunidades en desarrollo de software con ganas de aprender, sumar experiencia y aportar a un equipo.
